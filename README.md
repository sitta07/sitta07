### 🧠 What I work on

- **Multi-agent systems & orchestration** — LangGraph / LangChain pipelines, tool-using agents, evaluation with LangSmith (see [`AgentGraph`](https://github.com/sitta07/AgentGraph)).
- **Retrieval-augmented generation** — RAG pipelines and observability ([`RAGScope`](https://github.com/sitta07/RAGScope), [`OCR2Action-Engine`](https://github.com/sitta07/OCR2Action-Engine)).
- **Computer vision + MLOps** — end-to-end pill/box recognition with deep metric learning, vector search, and edge deployment ([`PillTrack`](https://github.com/sitta07/pilltrackMLops) family).
- **Career-intelligence AI** — resume/ATS optimization with multi-model pipelines ([`DaiJob`](https://github.com/sitta07/DaiJob)).
- **Computational neuroscience (research)** — a local-first spiking-neural-network lab: LIF neurons, STDP, reward-modulated learning & affect dynamics (NeuralMind, in [`AgentGraph`](https://github.com/sitta07/AgentGraph)).
- **Teaching** — an AI foundations course in Thai ([`ai-course-tier1-starter`](https://github.com/sitta07/ai-course-tier1-starter)).
