### What I build

- 🤖 **AI agents** that use tools and work together to finish a task — e.g. [AgentGraph](https://github.com/sitta07/AgentGraph), a multi-agent system for designing and reviewing software architecture.
- 📄 **Document AI** — reading documents, answering questions from them, and turning them into actions. See [OCR2Action-Engine](https://github.com/sitta07/OCR2Action-Engine) and [RAGScope](https://github.com/sitta07/RAGScope) (a tool to compare how well different search strategies work).
- 👁️ **Computer vision + MLOps** — a full pipeline that recognises medicine packs from photos and runs reliably in production ([PillTrack](https://github.com/sitta07/pilltrackMLops)).
- 🧑‍💼 **Career AI** — [DaiJob](https://github.com/sitta07/DaiJob), which helps job seekers improve their resumes and pass automated screening.
- 🧠 **Research** — a small brain simulator (spiking neurons, learning, and simple "emotion" signals) you can run on a laptop, inside [AgentGraph](https://github.com/sitta07/AgentGraph).
- 📚 **Teaching** — a beginner-friendly AI course in Thai: [ai-course-tier1-starter](https://github.com/sitta07/ai-course-tier1-starter).
